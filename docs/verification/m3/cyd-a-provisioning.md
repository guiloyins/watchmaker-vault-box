# CYD A provisioning and initial network check

Rafa selected reuse of the locally saved Guilo Wi-Fi settings. The settings were copied directly into an owner-only, Git-ignored Vault provisioning file, together with a newly generated controller credential. No Wi-Fi password or bearer key is included in the evidence. The isolated Phoenix deployment is `data/m3-hardware`; its simulated box and registered `cyd_a`/`cyd_b` identities are independent of the earlier browser demo.

The first controller accepted `provision.set` at service revision 1 while retaining its factory identity. An explicit service reboot committed revision 2. Subsequent inspection returned `cyd_a`, `configured:true`, the expected profile hash, `reboot_required:false`, and no storage fault. Separate post-reboot serial opens retained the same boot ID. [Nonsecret receipts and readback](cyd-a-provisioning.json) · [macOS serial correction](cyd-a-serial-service.md).

The development Phoenix listener passed its health check at `http://192.0.2.103:4013`. Its device endpoint is `ws://192.0.2.103:4013/device/v1`, with trusted-LAN plaintext mode explicitly selected on host and controller. An independent simulator using the same registered `cyd_a` credential connected and observed the lobby; this verifies host routing and credential setup. It does not establish physical Wi-Fi/WebSocket acceptance.

The physical controller's status still had `binding:null`. An ARP entry associated its MAC with `192.0.2.101`, but a current two-packet ping received no replies; the ARP entry alone does not establish a current connection. A packet-metadata-only capture could not run because macOS denied access to its BPF device. No packet payload or credentials were captured.

LCD/touch observations are pending. The initial firmware collapses startup and connection failures into “Connecting”; the diagnostic follow-up now adds bounded network phase/stage and numeric errors on the LCD, including during calibration. Its clean build, three image hash verifications and NVS-preserving postflash readback passed; revision 2 and configured identity were retained. [Diagnostic image and installation](network-diagnostics-build.json). Service frames and protocol v1 remain unchanged. Calibration, controller service exit, physical gameplay, network resource measurements, certificate-verified WSS and power-bank checks are not yet passed.
