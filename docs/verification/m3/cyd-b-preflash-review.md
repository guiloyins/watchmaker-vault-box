# CYD B independent preflash review

The November 13 ROM transcript reports base MAC `02:00:00:00:fe:01`, ESP32-D0WD-V3 revision 3.1, a 40 MHz crystal and 4 MiB flash with JEDEC manufacturer `0x5e`, device `0x4016` and a 3.3 V strap. The MAC matches Guilo’s historical `cyd_a`. Both legacy environments inherit the same tracked display and touch configuration. Rafa also confirmed the two yellow terminals share the same PCB revision. These sources support the profile’s first-flash wiring. [ROM and historical source review](../../hardware/cyd-b-profile-review.md)

The repository profile validator accepted `cyd-yellow-ili9341-unit-b-bgr`. Its canonical SHA-256 is `789e32ace8116fab55704c7fce938a91b44b3e075472daefc09243a91617f16e`. All hardware and layout fields match Vault CYD A’s BGR profile. CYD B uses ILI9341 SPI2 at 20 MHz on SCLK 14, MOSI 13, MISO 12, CS 15 and DC 2, with no dedicated reset and an active-high GPIO 21 backlight. XPT2046 touch uses SPI3 at 500 kHz on SCLK 25, MOSI 32, MISO 39 and CS 33, with IRQ 36. USB service is UART0 on GPIO 1/3. BGR, inversion and the 240 × 320 X-mirrored portrait setup carry over from CYD A. [CYD B profile](../../../firmware/boards/cyd-yellow-ili9341-unit-b-bgr/profile.json) · [CYD A profile](../../../firmware/boards/cyd-yellow-ili9341-unit-a-bgr/profile.json)

The declared flash configuration is 4 MiB DIO at 40 MHz with internal RAM only. The partition table is at `0x8000`, NVS occupies `[0x9000, 0x20000)`, and the 3 MiB factory slot occupies `[0x20000, 0x320000)`. Generated settings select the physical target, enable BGR, and leave the provisioning predecessor empty. The approved MAC list contains only CYD B. Normal app source has USB touch tracing disabled and verifies `WIFI_PS_NONE` before starting the network worker. [Profile generator](../../../tools/firmware/profile_config.py#L292) · [Normal image flag](../../../firmware/apps/cyd/main/touch_trace_config.hpp#L7) · [Network startup](../../../firmware/apps/cyd/main/network_adapter.cpp#L121)

The flash wrapper validates the manifest and artifact hashes, then verifies target, MAC and flash capacity on the same ROM connection before erasing or writing. Explicit first-install NVS initialization requires the protected full-flash backup and its matching 4,194,304-byte size and SHA-256 record. It verifies that the current partition table matches the backup, checks for secure boot and flash encryption, and reads back the erased NVS region. The backup retry was in progress during this review. The profile passed independent preflight for build. Backup validation, flash, and CYD B’s own color, orientation, calibration, normal play and power checks remain separate observations.
